# git-github-weekly-task

## About
This repository contains my practical Git and GitHub weekly task.

## Topics Covered
-	Git installation and configuration :
   Install Git on your computer and configure your name and email. These details are used to identify who made each commit.
-	GitHub repository :
  A repository (repo) is a place on GitHub where you store and manage your project files and Git history
-	Clone, commit and push :
   Clone downloads a GitHub repository to your computer. Commit saves your changes in Git history. Push uploads your commits from your computer to GitHub.
-	Branching and merging :
  A branch lets you work on a feature separately from the main code. Merge combines the changes from one branch into another branch.
-	Rebase :
  Rebase moves your branch changes on top of the latest changes from another branch. It helps keep the project history clean and linear
-	Pull Requests :
  A Pull Request is a request to review and merge your changes from one branch into another, usually main. Team members can review the code before merging.
-	README.md :
  README.md is a documentation file that explains your project, such as project purpose, installation steps, usage, and features. It is normally displayed on the               repository's main page.
-	.gitignore :
  .gitignore tells Git which files or folders should not be tracked or uploaded, such as passwords, temporary files, logs, or build files.
